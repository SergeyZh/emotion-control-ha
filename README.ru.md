# ESPHome ↔ L&S Emotion Control (CC2500)

Управляйте мебельными светильниками **L&S Emotion Control** из **Home Assistant** — без шлюза
производителя. ESP32 с радиомодулем **CC2500** (2.4 ГГц) прикидывается вашим пультом: передаёт
те же команды и **слушает эфир**, поэтому нажатия физического пульта тоже видны в HA.

Лампа появляется в Home Assistant как обычный светильник: вкл/выкл, яркость, цветовая температура.

**Статус: рабочее**, проверено на реальной лампе. Протокол расшифрован в отдельном репозитории
[`emotion-control-re`](https://github.com/SergeyZh/emotion-control-re).

Поддерживаются два варианта протокола:

- исходный широковещательный протокол с 14-байтовыми кадрами и четырёхбайтовым ID пульта;
- адресный протокол с 8-байтовыми кадрами, проверенный с **L&S Emotion Driver ED 12/30-1** и его
  двухкнопочным пультом (правая кнопка: вкл/выкл и яркость при удержании; левая: температура цвета).

## Что умеет
- **Включение/выключение** и **цветовая температура** (тёплый ↔ холодный).
- **Яркость** — как обычный слайдер в HA (штатные ступени в 14-байтовом варианте, короткие
  рассчитанные по времени ходы в 8-байтовом).
- **Синхронизация с пультом:** используете физический пульт — состояние в HA обновляется.
- **Сохранение состояния** при перезагрузке ESP.
- **Поиск ID пульта** в эфире (компонент-сниффер) — своего и любых чужих в радиусе приёма.
- **Сопряжение** с лампой напрямую в 14-байтовом варианте, если не хотите клонировать существующий
  пульт. Для 8-байтового варианта сопряжение пока не проверено.

## Что понадобится
| Компонент | Требования |
|---|---|
| **ESP32** | Любая плата. Проверено на DevKit V1 (ESP-WROOM-32) |
| **Модуль CC2500** | Именно 2.4 ГГц (**не** CC1101 — он суб-гигагерцовый), кварц **26.000 МГц**. Проверены [маленький модуль с площадками](https://de.aliexpress.com/item/1005005501196142.html) и [модуль TinyTronics с ножками](https://www.tinytronics.nl/en/communication-and-signals/wireless/rf/modules/cc2500-wireless-rf-module-2.4ghz) |
| **Паяльник** | Нужен только для модуля без установленной гребёнки |
| **Пульт L&S** | Ваш существующий пульт — из него берётся ID. Либо лампа в режиме сопряжения |

У маленького модуля с AliExpress девять площадок с шагом **1.27 мм**, поэтому шесть проводов к нему
нужно припаять. Проверенный модуль TinyTronics уже имеет ножки и подключается к гребёнке ESP32
проводами Dupont «мама–мама» без пайки радиочасти. Порядок ножек на разных платах отличается:
ориентируйтесь по названиям сигналов (`SI`, `SCLK`, `SO`, `CSn`, `GDO0`, `VCC`, `GND`), а не по
номерам площадок в таблице ниже.

Питание модуля — **3.3 В**, не 5 В. Распиновка, чертёж платы и схема —
[`datasheets/`](datasheets/CC2500_module_pinout.md).

### Подключение (модуль CC2500 → ESP32, SPI)
| Модуль | Сигнал | ESP32 (пример, VSPI) |
|---|---|---|
| SI (2) | MOSI | GPIO23 |
| SCLK (3) | SCLK | GPIO18 |
| SO (4) | MISO | GPIO19 |
| CSn (8) | CS | GPIO5 |
| GDO0 (7) | конец передачи (опц.) | GPIO4 |
| VDD (1) / VSS (6) | 3V3 / GND | 3V3 / GND |

`GDO2` не используется. `GDO0` необязателен — без него конец передачи определяется опросом чипа.

## Быстрый старт
```bash
# 1. ESPHome (пример — venv в каталоге проекта)
python3 -m venv .venv && ./.venv/bin/pip install esphome

# 2. Узнать ID своего пульта: прошить сниффер и понажимать кнопки на пульте
./.venv/bin/esphome run sniffer.yaml --device /dev/cu.usbserial-0001
#    → [I][cc2500_emotion_sniffer]: remote 68049F25  cmd=0x01 (on)  val=0x80  RSSI=-38 dBm  LQI=2 …

# 3. Wi-Fi в secrets.yaml, найденный ID — в remote_id внутри example.yaml
printf 'wifi_ssid: "ВашаСеть"\nwifi_password: "пароль"\nemotion_remote_id: "68049F25"\n' > secrets.yaml

# 4. Прошить боевой конфиг (первый раз по USB, дальше можно по OTA)
./.venv/bin/esphome run example.yaml --device /dev/cu.usbserial-0001
```

Признак того, что радио живо:
```
CC2500 PARTNUM=0x80 VERSION=0x03
Radio configured and calibrated.
Listening for remote commands (RX enabled, MARCSTATE=0x0D).
```

Пошагово и с объяснениями — **[GETTING-STARTED.ru.md](GETTING-STARTED.ru.md)**.

## Минимальный конфиг
```yaml
external_components:
  - source: github://SergeyZh/emotion-control-ha
    components: [cc2500_emotion]

spi:
  clk_pin: GPIO18
  mosi_pin: GPIO23
  miso_pin: GPIO19

cc2500_emotion:
  id: emotion
  cs_pin: GPIO5
  gdo0_pin: GPIO4
  remote_id: "68049F25"   # 4-байтовый ID или 3-байтовый маршрут вроде "68ABF2"

light:
  - platform: cc2500_emotion
    name: "L&S Emotion"
    cc2500_emotion_id: emotion
```
Все опции — в [CONFIGURATION.ru.md](CONFIGURATION.ru.md). Готовые конфиги: [`example.yaml`](example.yaml)
(боевой, с Wi-Fi), [`bench.yaml`](bench.yaml) (стенд по USB), [`sniffer.yaml`](sniffer.yaml)
(только приём).

## Как это работает
CC2500 настраивается снятой с пульта картой регистров (MSK, 250 kBaud, 2436.2 МГц, sync `0xD391`,
FEC, аппаратный CRC) — модуляцию, кодирование и CRC кадра чип делает сам. Софт готовит либо
8-байтовый адресный payload, либо 14-байтовый широковещательный.

Чип держится в приёме и возвращается в него после каждой передачи. Принятые кадры проверяются
(CRC, длина, контрольная сумма) — те, что пришли с вашего `remote_id`, обновляют состояние в HA
**без обратной передачи**; остальные достаются сниффер-компоненту, так и находится ID пульта.

## Ограничения
- **Обратная связь зависит от варианта.** Лампа с 14-байтовым протоколом не отвечает, поэтому её
  состояние в HA — оценка. ED 12/30-1 отвечает на адресные 8-байтовые команды, но самостоятельно
  изменения состояния не публикует; эфир физического пульта всё равно синхронизирует HA.
- **Яркость представлена настраиваемым числом ступеней** (по умолчанию пять). В 14-байтовом варианте
  это штатные шаги, в 8-байтовом каждый шаг приближён коротким ходом яркости по времени.
- **Плавное удержание кнопки пульта** оценивается по времени, поэтому приблизительно.
- **После перезагрузки ESP** состояние восстанавливается, но лампе не передаётся (она помнит своё
  сама) — если её меняли пультом за это время, HA выровняется при первом действии.

Полный список особенностей — в [CONFIGURATION.ru.md](CONFIGURATION.ru.md#особенности-и-ограничения).
